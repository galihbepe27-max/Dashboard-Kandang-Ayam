# Dashboard-Kandang-Ayam

Sistem Monitoring dan Pengendalian Otomatis Kandang Ayam Berbasis IoT.

## Fitur
- Monitoring suhu DHT22
- Monitoring kelembapan DHT22
- Monitoring gas amonia MQ-137
- MQTT Realtime
- Dashboard Tkinter
- Grafik realtime
- Status kualitas udara
- Kontrol lampu otomatis
- Kontrol kipas otomatis

## Hardware
- ESP32
- DHT22
- MQ-137
- Relay
- Lampu
- Kipas

## Software
- Python
- Tkinter
- MQTT
- Matplotlib
